On GitHub Copilot, load JStack skills by their bare names through the `skill` tool (`jedi-mode`, `tdd`, `architect`, not `jstack:jedi-mode`); the plugin's agents keep the prefix (`jstack:jedi-agent`, `jstack:comment-sicko`). Copilot lists only part of a large plugin's skills in its prompt; every JStack skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a JStack skill names through `references/copilot-tools.md` in the `jedi-mode` skill directory. JStack ships no default Copilot models. A skill that dispatches on role models takes them from the user's saved JStack model choices. The plugin hook reads them from the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/jstack-models.md`, checks them, and adds them to the end of this block. Do not `view` the sheet. It sits outside the workspace, so reading it asks for path access. After `setup-jstack` writes the sheet in this session, use the values it just wrote.

Skills that dispatch on role models: `architect`, `arena`, `how`, `interrogate`, `jedi-mode`, `reflect`, `swarm`, `why`.
